# Entraînement Logique

Jeu de révision du cours de logique de L1 : numération, logique propositionnelle (syntaxe, sémantique, équivalences, formes normales) et logique des prédicats.

- 7 chapitres de 10 questions corrigées
- Exercices type TD en plusieurs questions (conversions, étude d'une formule, simplification guidée, mise en forme normale, prédicats, syllogismes, rédaction)
- Fiches de cours, entraînement libre, statistiques et examen blanc de 20 minutes

Le jeu tient dans un seul fichier, `index.html`, et marche dans n'importe quel navigateur, hors ligne. La progression est enregistrée dans le navigateur.
